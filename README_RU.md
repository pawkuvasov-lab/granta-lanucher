# Granta Car Launcher — Нативный Android-лаунчер для автомагнитолы (Kotlin / Jetpack Compose)

Этот проект содержит полный исходный код приложения-лаунчера для Android-магнитолы (ГУ Teyes CC3, Topway TS10/TS18, FYT, МТС, Mekede и стандартных Android 8.0–14 ГУ), разработанный по вашему дизайн-макету.

## Реализованный функционал в нативном коде

1. **Режим домашнего экрана (`CATEGORY_HOME` и `CATEGORY_CAR_MODE`)** — в `AndroidManifest.xml` прописаны системные фильтры, благодаря которым магнитола назначает приложение главным экраном по нажатию кнопки `HOME`.
2. **Считывание скорости по GPS-датчику (`GpsSpeedService.kt`)** — опрос `LocationManager.GPS_PROVIDER` с частотой 5 Гц (200 мс), фильтрация шума на стоянке, подсчёт количества активных спутников (`GnssStatus`), расчёт суточного пробега (одометра) и автоматическая корректировка громкости от скорости движения (**ASL / Авто-громкость**).
3. **Управление музыкой по Bluetooth и свайп-панель справа (`CarMediaAndNavListener.kt`)**:
   - Интеграция с `MediaSessionManager` и профилем Bluetooth **AVRCP 1.6**: отображение текущего исполнителя и названия трека, прогресс-бара, кнопок `Prev` / `Play-Pause` / `Next`.
   - Свайп справа налево открывает выезжающую панель очереди воспроизведения (`MediaSession.QueueItem`), где нажатием на любую песню вызывается `transportControls.skipToQueueItem(queueId)`.
   - Вкладка **«FM Радио»** и кнопка быстрого переключения: отправляет системный `Intent` на запуск и перестройку частоты штатного радио-модуля магнитолы (`com.ts.MainUI`, `com.syu.radio`, `com.android.fmradio`, `com.microntek.radio`).
4. **Интеграция с Яндекс.Навигатором (`NotificationListenerService`)** — сервис перехватывает системные уведомления `ru.yandex.yandexnavi` и `ru.yandex.yandexmaps`, извлекая дистанцию до манёвра (`Через 200 м`), направление (`поворот налево`) и время/расстояние до финиша (`До финиша: 12 км • 18 мин`).
5. **Настраиваемый док приложений слева снизу (`AppDockRepository.kt`)** — сканирует установленные на магнитоле приложения через `PackageManager.queryIntentActivities`, позволяет закреплять и откреплять любые приложения на главном экране в 1 клик.
6. **OBD2 / ELM327 Телеметрия (`ObdElm327Manager.kt`)** — чтение температуры охлаждающей жидкости (`PID 0105`), оборотов двигателя (`PID 010C`) и напряжения бортовой сети (`ATRV`).

## Как собрать готовый `.apk` файл за 2 минуты

### Способ 1: В Android Studio (на ПК)
1. Распакуйте архив `GrantaCarLauncher_AndroidProject.zip`.
2. Откройте папку проекта в **Android Studio (Iguana / Jellyfish / Koala или новее)**.
3. Дождитесь автоматической синхронизации Gradle и выберите в верхнем меню **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. Готовый установочный файл появится по пути `app/build/outputs/apk/debug/app-debug.apk`.

### Способ 2: Облачная сборка без установки программ (через GitHub Actions)
В проект уже встроен файл автоматической сборки `.github/workflows/build-apk.yml`:
1. Загрузите файлы из архива в любой бесплатный репозиторий на GitHub.
2. Перейдите во вкладку **Actions** → выберите **Build Granta Car Launcher APK** → нажмите **Run workflow**.
3. Через ~90 секунд скачайте скомпилированный `GrantaCarLauncher-debug.apk` в разделе Artifacts и установите его на магнитолу с флешки.

## Разрешения при первом запуске на магнитоле
После установки APK на магнитолу выдайте следующие разрешения:
- **Геолокация (Всегда)** — для работы GPS-спидометра и одометра.
- **Доступ к уведомлениям (Notification Access)** в настройках Android → для отображения манёвров из Яндекс.Навигатора и очереди треков Bluetooth.
- **Приложение главного экрана по умолчанию (Home App)** — выберите `Granta Car Launcher`.
